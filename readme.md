# Lock-n-Trust
**Lock n Trust** is a secure digital vault system inspired by DigiLocker.  
It allows users to safely **store, manage, and access important documents** with added layers of trust and security.  

---

##  Features  
-  Secure Authentication (with optional Face Recognition)  
-  Upload, Store & Organize Documents  
-  AI/ML Integration (Planned: Document Classification & Smart Search)  
-  Simple and User-Friendly Interface  
-  Privacy-Focused Document Management
